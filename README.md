# Supply Chain Analysis

## Overview
Analyzed 259,971 supply chain orders to identify delivery patterns,
regional performance and shipping trends.

## Tools Used
- MySQL Workbench (SQL queries)
- Python (Pandas, Matplotlib)
- Power BI (Dashboard)

## Key Findings
- Late delivery rate: 55% (145,383 orders)
- Top Market: LATAM with 75,096 orders
- Most used shipping mode: Standard Class
- Shipping canceled: 9,763 orders

## Files
- `analysis.py` — Python analysis script
- `supply_chain_cleaned.csv` — Cleaned dataset
- `supply_chain_dashboard.pbix` — Power BI dashboard
- `supply_chain.png` — Delivery status chart
